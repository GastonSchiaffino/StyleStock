# Style Stock - Full

Proyecto JavaFX + SQLite para control de stock y facturación de productos.
Incluye CRUD de productos, clientes y facturas; creación automática de la DB;
generación de PDF de factura; tema claro/oscuro seleccionable y guardado.

## Requisitos
- JDK 17 (recomendado)
- IntelliJ IDEA
- Maven

## Ejecutar desde IntelliJ
1. Importar como proyecto Maven.
2. Ejecutar `com.style.stock.Main`.

## Notas
- La DB se crea en el directorio de usuario: ~/style-stock/style_stock.db
- Las facturas PDF se guardan en: ~/style-stock/facturas/
- Preferencias (tema) se guardan en: ~/style-stock/config.properties
- Para acceso remoto recomendo AnyDesk o TeamViewer para soporte puntual.
